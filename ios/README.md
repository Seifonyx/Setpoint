# Setpoint for iPhone (native, SwiftUI)

- `project.yml` describes the Xcode project; the build server turns it into `Setpoint.xcodeproj` with XcodeGen.
- `Setpoint/`: `App/` (app shell, design, settings, intents, update check), `Features/` (screens), `Model/` (Store,
  Engine bridge, Account and sync, formats), `Resources/` (strings, demo data, fonts, legal; `engine.js` and
  `foods.json` are generated by `node engine/build.js`), `Shared/` (shared with the widgets).
- `Widgets/`: widgets and the Live Activity. `UITests/`: the UI tests the build runs before every release.
- `legal/`: the app's legal pages; `node ios/legal/build.js` writes `Setpoint/Resources/Legal.json`.
- Every push builds on GitHub (`.github/workflows/ios.yml`) and, when the tests pass, publishes `Setpoint.ipa` and
  simulator screenshots to the **ios-latest** release and updates `sidestore.json`.
- Install: on the iPhone, open https://github.com/Seifonyx/Setpoint/releases/tag/ios-latest, download `Setpoint.ipa`,
  and open it in SideStore.
- Minimum iOS 26 (Liquid Glass).
